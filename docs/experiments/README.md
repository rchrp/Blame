# Experiments

Each folder here keeps an experiment's written summaries. The raw data (traces, journals, ledgers, input bundles, frozen lockfiles and JSON results) lives in [rchrp/blame-research](https://github.com/rchrp/blame-research), pinned below at commit `f9100665`. It was moved there on 2026-11-04 to keep this repository light: it made up 93% of its files by size.

That archive's `experiments/` folder is byte-identical to this folder at commit `3bcaf929` (git tree `ab071d04`). Earlier versions remain in this repository's history.

To rerun a study, copy the experiment from the archive into `docs/experiments/<experiment>`. The study scripts are in `tools/terminal_bench`. `.gitignore` keeps everything here except Markdown untracked, so new raw data goes to the archive rather than this repository.
