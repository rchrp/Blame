# Design the screen

Start with the brief, the project's components and the visitor's next decision. On a cinema booking page, put today's films, times and seats within reach of booking. On a ceramics page, let an actual piece and the maker's note set the composition. Use the project's own assets and facts.

For a redesign, inspect the existing screen. When a preview is available, keep a before capture of the affected view. Preserve the data, actions and working paths. Pick the change that most improves the task and apply the relevant corrections below. For a planning request, return the direction. For a small refinement, stay within the requested area.

Verify in the available app or component preview. Compare the same route, state and width after editing. For a responsive page, check wide and narrow together. Fix observed defects in one batch and confirm the affected views.
