# Compose a new screen

Who is here, what will they do, and what can you show them? Draft the key words or data first. Build the opening view around the most useful item and its action. Label sample data. For planning, return this direction.

- **Architecture portfolio.** Open on a project photograph. Let its proportions set the grid. Keep its name and location in a quiet caption, including on mobile.
- **Invoice workspace.** Lead with invoices due, sorted by date. Align amounts with tabular figures. Keep each due date, amount and follow-up action together on mobile.

Reuse the project's type, palette and components. For a new identity, borrow one detail from the material, such as the caption style in an architect's drawings. Check the first render at wide and narrow widths with the corrections below.
