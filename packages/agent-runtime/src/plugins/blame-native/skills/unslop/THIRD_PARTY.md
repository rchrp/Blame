# Sources for Blame’s Unslop skill

The primary source is [Unslop by Damir Sokolovsky (@heydamir)](https://github.com/heydamir/unslop/tree/620163eedb3529d9cd23a3994ed8d287d06f760d), under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The [license text](licenses/CC-BY-4.0.txt) is included. Blame condensed and adapted the diagnostic and refinement workflow for its own agent and preview tools. The files in `references/` are unmodified copies from that revision. The dashboard comparison uses the first and last panels of the original contact sheet, placed side by side, encoded as JPEG and annotated separately by Blame. The Unslop material and its adaptations in this skill are available under CC BY 4.0.

Project grounding and bounded visual verification carry forward guidance adapted from [Impeccable 4.1.1 by Philipp Bakaus](https://github.com/pbakaus/impeccable), under the [Apache License 2.0](licenses/Apache-2.0.txt).

The new-screen guide adapts the sequence from [Taste Skill’s creation workflow](https://github.com/Leonxlnx/taste-skill/blob/6c0b5c78f5d31776e2210305abaa210cdc0030bf/skills/taste-skill/SKILL.md#4-the-run). Blame wrote the portfolio and invoice examples. The heading, typography and content examples also draw on [Hallmark’s design checks](https://github.com/Nutlope/hallmark/blob/04977e15f3dfd6ee4b74c887dac3eb52665d6c92/skills/hallmark/references/gates.md) and [Taste Skill’s copy patterns](https://github.com/Leonxlnx/taste-skill/blob/6c0b5c78f5d31776e2210305abaa210cdc0030bf/skills/taste-skill/references/copy-tells.md). The accessibility review draws on [Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines/blob/434b7f91364665f2f733b310ec54809bf8f37937/command.md). These projects use the MIT License.
