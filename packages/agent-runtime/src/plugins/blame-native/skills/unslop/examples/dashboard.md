# Unslop dashboard comparison

Left shows the original dashboard. Right shows the final frame.

- **Read the heading.** The greeting becomes the reporting month. Visitors can now interpret “Paid this month” against a period.
- **Follow the color.** The original search field, selection, counts and chart all compete. On the right the sidebar recedes, plan colors distinguish categories, and the chart carries the strongest color.
- **Compare the same amount.** Both panels show $48,210. The final label uses sentence case, the flame disappears, and the change has a comparison period. These changes give the figure context.
- **Apply the lesson to this project.** Choose what should draw attention, then simplify what competes with it. Preserve real series, time ranges and accessible contrast when applying this treatment.
