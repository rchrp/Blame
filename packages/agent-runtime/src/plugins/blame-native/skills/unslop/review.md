# Review the screen

Follow the main task with realistic data. Use the current render when available. Locate the first element that attracts attention and the first place a visitor could hesitate. Apply the relevant comparisons below. A mark of deliberate branding can stay when it serves the brief.

For each material finding, name the element, the consequence and the smallest useful correction. Test a critical action with the keyboard, including visible focus and field errors. Check a narrow view for hidden actions or clipped values. Distinguish observed defects from questions that need a render.

For audit or critique alone, report findings. When changes are requested, compare before and after at the same state and viewport, then check the affected interaction once.
