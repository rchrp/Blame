title: AI providers

Blame runs on your own credentials, and your provider bills you directly. It connects to your Claude or ChatGPT plan, to API keys for OpenAI, Anthropic, OpenRouter, and Gemini, and to any OpenAI-compatible API, local models included. You can connect several, and use a different model for each story.

Connections live in **Settings → Models & Providers**, under **Provider connections**. Choose **Connect provider**, then pick a provider: the dialog groups them under **Use your subscription** and **API keys**. The first-launch setup offers the same choice.

## Use your Claude plan

Blame uses your Claude Pro or Max plan through Claude Code, running on your computer, and keeps its own tools and checks.

<Steps>
<Step>

### Install Claude Code

On macOS and Linux:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

On Windows (PowerShell):

```powershell
irm https://claude.ai/install.ps1 | iex
```

</Step>
<Step>

### Sign in with your Claude account

```bash
claude auth login
```

If Claude Code is signed in with an API key instead, usage is billed to that key: sign in again to use your subscription.

</Step>
<Step>

### Connect to Blame

In **Connect Claude Code**, choose **Connect Claude Code**. Usage counts against your Claude plan limits.

</Step>
</Steps>

## Use your ChatGPT plan

Under **Use your subscription**, choose ChatGPT, then sign in with your ChatGPT account in the browser that opens. If another ChatGPT sign-in is already open (Codex or another app), finish or close it first.

## Use an API key

Pick the provider under **API keys**, give the connection a name (for example "Work"), and paste the key. A provider can have several connections: use **Add connection** for another key.

Provider keys are encrypted. Without an account, the key that encrypts them is held by your system keychain.

## Use an OpenAI-compatible endpoint

Choose **OpenAI Compatible**, then enter the endpoint's **Base URL** (for example `https://provider.example/v1`) and at least one **Model ID**.

## Choose the models

**Settings → Models & Providers → Default models** sets two models:

- **Agent model**: development sessions, backlog execution, and chat.
- **Alternative model**: project setup, security audits, and prompt optimization. Blame also uses it to approve and merge a story.

To change the model of one story, use the model picker in the story's comment box: it picks the model and reasoning of that story's next turn, without changing the default for new stories.
